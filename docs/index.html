하루매일 HaruMaeil

바탕화면에 붙는 가벼운 캘린더 위젯. 구글 캘린더와 구글 할 일을 함께 봅니다.

무엇을 하나요

  • 바탕화면 위젯 — 아이콘 뒤에 달력이 붙습니다. 창을 띄우지 않아도 이번 달이 보입니다.
  • 구글 캘린더 연동 — 본인 계정의 일정을 가져와 표시합니다.
  • 구글 할 일(Tasks) 연동 — 일정과 할 일을 한 화면에서 봅니다. 유료 캘린더 앱도 잘 지원하지 않는 부분입니다.
  • 가벼움 — Tauri로 만들어 설치 용량과 메모리 사용이 작습니다.

어떻게 만들어졌나요

Tauri + Svelte + Rust로 만든 Windows 데스크탑 앱입니다. 일정은 내 PC의 SQLite 파일 하나에 저장하고, 별도의 서버를 두지 않습니다.

개인정보

하루매일은 서버가 없습니다. 일정과 할 일은 사용자의 컴퓨터에만 저장되고, 개발자를 포함한 누구에게도 전송되지 않습니다. 자세한 내용은 개인정보처리방침을 확인하세요.
